Added the `@utrecht/icons-react` package: every icon from `@utrecht/icon` as a React component, for example `IconArrow`. The SVG is plain JSX, so you do not need the web components. Import an icon from `@utrecht/icons-react`, or from its own file, for example `@utrecht/icons-react/arrow`, to load only that icon.
